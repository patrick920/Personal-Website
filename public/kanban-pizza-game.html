Agile Kanban Pizza Game Group Project

University Group Project

  • HTML
  • JavaScript
  • Phaser

I worked in a group on a web-based Kanban pizza game designed to teach students how to use Agile principles (Agile is a methodology to organise work). HTML, JavaScript and the Phaser game library were used. AI tools were used to assist the development. A Kanban board was used to organise pizza orders in a virtual restaurant, with each column being a station in the restaurant. Below are images of the game in action:
