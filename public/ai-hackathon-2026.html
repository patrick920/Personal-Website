Winner - Wellington AI Hackathon 2026

  • Claude Code
  • HTML
  • CSS
  • JavaScript

I won the Wellington AI Hackathon 2026 with two other people. I developed and presented a prototype website to reuse waste in New Zealand’s primary industries using Claude Code, as part of a three-person team over two days. I developed a website using HTML, JavaScript and CSS. The site worked similarly to a marketplace where organisations that have waste to dispose of e.g. kiwifruit skin can list it and others can acquire the waste. An AI chatbot was integrated into the website, allowing users to search for waste products or even create their own listings using the AI’s help. I made a document outlining the specifications of the website, wrote a detailed prompt message and provided this to Claude Code. After the code was generated, I tested the website extensively and made follow-up prompts to fix the issues I found. This has helped me to understand how to use Claude Code effectively. My team was one of four teams nationwide to be selected to present at the Aotearoa AI Summit 2026 at the Tākina Wellington Convention and Exhibition Centre.
